C-command

A node c-commands another node if every branching node dominating the first also dominates the second, and the first does not dominate the second.

It is a structural relationship between two nodes in a tree and asks if these two things are in the right hierarchical relationship.

Example

In the English sentence, "John likes himself", John c-commands himself.

Tree Diagram

                   S
                /     \
              NP       VP
              |       /  \
             John    V    NP
                     |     |
                    likes himself

Alternative view

The best way to picture c-command is as a family tree: a node c-commands its sister and everything descended from her. In other words, it c-commands its siblings, its nieces and nephews, and their kids, but never its own children or its parents.

Practice

1. In The dog chased the cat, does the subject the dog c-command the object the cat?

Show answer

Yes. The first branching node above the dog is TP, and TP dominates the cat. Neither one dominates the other.

2. Why is *Mary's brother likes herself ungrammatical?

Show answer

A reflexive needs an antecedent that c-commands it. Mary sits inside the subject DP Mary's brother, so it doesn't c-command herself. The only c-commanding DP is Mary's brother, which is masculine, so herself has no fitting antecedent.

3. In Hindi, Ram ne khaana khaaya, does the subject Ram c-command khaana?

Show answer

Yes. The first branching node above Ram is TP, and TP dominates khaana. Neither one dominates the other. Hindi is head-final (SOV), so the object comes before the verb, but the hierarchy is the same as in English.
